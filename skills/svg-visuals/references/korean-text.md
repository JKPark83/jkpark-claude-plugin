# korean-text — 한글 라벨이 박스를 넘치지 않게

SVG의 `<text>`는 **자동 줄바꿈이 없다.** 넘치면 박스 밖으로 그냥 튀어나간다.
그래서 폭을 눈대중으로 잡으면 반드시 깨진다. 좌표를 잡기 **전에** 계산한다.

## 폭 산식

폰트 크기 `S`(px)일 때 글자 하나의 대략적인 폭:

| 문자 종류 | 폭 |
|---|---|
| 한글 | `S × 1.0` |
| 영문 대문자·숫자 | `S × 0.62` |
| 영문 소문자 | `S × 0.55` |
| 공백 | `S × 0.3` |
| 모노스페이스 (`d-t-code`) | `S × 0.60` (문자 종류 무관) |

**텍스트 폭** = 위 값들의 합.
**박스 폭** = `max(120, 텍스트 폭 + 32)` — 좌우 여백 16씩.

`d-t`(14px) 기준 실측 근사:

| 라벨 | 계산 | 박스 폭 |
|---|---|---|
| `인증` | 2 × 14 = 28 | 120 (최소값) |
| `사용자 요청` | 5×14 + 1×4.2 ≈ 74 | 120 (최소값) |
| `토큰 검증 서버` | 7×14 + 1×4.2 ≈ 102 | 134 |
| `요청 본문 파싱 및 검증` | 11×14 + 2×4.2 ≈ 162 | 194 |
| `POST /users` | 4×8.7 + 1×4.2 + 7×7.7 ≈ 93 | 125 |

빠른 암산: **한글 N자 ≈ 14N px**, 여기에 32을 더하고 120과 비교한다.

## 라벨이 길 때

폭이 **200을 넘으면** 그대로 두지 말고 순서대로 시도한다.

1. **줄인다.** `요청 본문 파싱 및 검증` → `본문 검증`. 그림 라벨은 완전한
   문장일 필요가 없다. 맥락은 캡션과 본문이 준다.
2. **두 줄로 나눈다.** 의미 단위로 끊는다. 박스 높이 48 → 68.
   ```html
   <text class="d-t d-c" x="200" y="140">
     <tspan x="200" dy="-8">요청 본문</tspan>
     <tspan x="200" dy="18">파싱 · 검증</tspan>
   </text>
   ```
   나눌 때 각 줄을 따로 계산하고 **긴 쪽**으로 박스 폭을 정한다.
3. **박스 밖으로 뺀다.** 부가 설명은 박스 아래 `d-t-sm`으로 놓거나 캡션으로
   옮긴다.

**세 줄은 쓰지 않는다.** 세 줄이 필요하다는 건 그 노드가 너무 많은 걸 담고
있다는 신호다. 노드를 쪼개거나 설명을 본문으로 옮긴다.

## 화살표 위 라벨

화살표 위 설명(`d-t-sm`, 12px)은 **6자 이내**로 쓴다. 선을 가리지 않게
`text-anchor="middle"`로 선 중점에 놓고 `y`를 선보다 **6 위**에 둔다.
선 위에 겹치면 라벨 뒤에 `fill="var(--d-canvas)"` 사각형을 깐다.

**이 사각형의 폭도 계산해야 한다.** 12px 기준으로 산식을 다시 돌린 뒤 `+8`.
고정값 52를 쓰면 `종료 코드 0`(62.6px) 같은 라벨에서 선이 글자 뒤로 비친다.

```
rect 폭 = 텍스트 폭(12px 기준) + 8
rect x  = 라벨 중심 x - rect 폭 / 2
```

```html
<!-- "실패 시" → 39.6 + 8 ≈ 48, 중심 312 → x = 312 - 24 = 288 -->
<rect x="288" y="118" width="48" height="16" fill="var(--d-canvas)"/>
<text class="d-t-sm d-c" x="312" y="126">실패 시</text>
```

12px 기준 자주 쓰는 값: 2자 ≈ 24, 3자 ≈ 36, 4자 ≈ 48, `A B` 형태는 공백 3.6을
더한다.

## 폰트 스택

`design-tokens.md`의 `<style>`이 이미 지정한다. **개별 그림에서 다시 지정하지
않는다.**

```
-apple-system, "Apple SD Gothic Neo", "Noto Sans KR", system-ui, sans-serif
```

macOS는 Apple SD Gothic Neo, 그 외는 Noto Sans KR 또는 시스템 기본으로 떨어진다.
**웹폰트를 `@import`하거나 `<link>`로 불러오지 않는다** — Obsidian은 오프라인에서
열리고, 외부 폰트는 언젠가 안 뜬다.

폰트가 바뀌면 실제 폭이 산식과 ±10% 정도 달라질 수 있다. 그래서 여백 32을
빠듯하게 잡지 말고, 애매하면 **넉넉한 쪽**으로 반올림한다.

## 자주 나는 사고

| 증상 | 원인 | 처방 |
|---|---|---|
| 글자가 박스 밖으로 나감 | 폭을 눈대중으로 잡음 | 산식으로 다시 계산 |
| 두 줄 라벨이 위아래로 삐져나감 | 박스 높이가 48인 채로 둠 | 68로 키우고 `y`를 중심으로 |
| 세로 정렬이 어긋남 | `dominant-baseline` 누락 | `class`에 `d-c` 추가 |
| `<tspan>` 둘째 줄이 왼쪽으로 밀림 | `tspan`에 `x` 없음 | 각 `tspan`마다 `x` 명시 |
| 화살표 라벨이 선에 겹침 | 배경 사각형 없음 | `d-canvas` 사각형을 뒤에 깔기 |
| 라벨 뒤로 선이 비침 | 배경 사각형 폭을 고정값으로 씀 | 12px 산식 + 8로 다시 계산 |
| 그룹 오른쪽이 텅 빔 | 그룹 폭을 728로 고정 | 마지막 박스 오른쪽 끝 + 16 |
