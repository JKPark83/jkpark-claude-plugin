# App Store Connect Fields

Field names are given as they appear in the Korean App Store Connect UI, so
they can be matched against `read_page` output during Step 5.

## Version page — 앱 스토어 탭

| 필드 (ko) | Field (en) | 제한 | 비고 |
|---|---|---|---|
| 앱 이름 | Name | 30자 | 앱 정보 탭에 있음 (버전 페이지 아님). 변경은 새 버전 제출 시에만 반영. |
| 부제 | Subtitle | 30자 | 앱 정보 탭. 이름과 함께 검색 색인에 들어간다. |
| 프로모션 텍스트 | Promotional Text | 170자 | 심사 없이 언제든 교체 가능 — 시의성 있는 문구를 여기에. |
| 설명 | Description | 4,000자 | 앞 2~3줄만 접히지 않고 보인다. |
| 키워드 | Keywords | 100자 | 쉼표 구분, 공백 금지. 이름·부제·카테고리는 이미 색인되므로 중복 금지. |
| 새로운 소식 | What's New | 4,000자 | 첫 제출에는 나타나지 않는다. |
| 지원 URL | Support URL | — | 필수. 실제로 열려야 한다. |
| 마케팅 URL | Marketing URL | — | 선택. |
| 저작권 | Copyright | 200자 | `2026 홍길동` 형식. `©`는 넣지 않는다. |

## 앱 심사 정보

| 필드 | 제한 | 비고 |
|---|---|---|
| 로그인 필요 | — | 체크하면 사용자 이름·암호가 필수가 된다. 계정 없이 시연 가능하면 체크하지 않는다. |
| 연락처 | — | 이름·성·전화번호·이메일. 심사팀이 실제로 연락하는 곳. |
| 메모 | 4,000자 | 재심사 사유, 시연 절차, 하드웨어 요구사항. |
| 첨부 파일 | — | 시연용 오디오·영상. 시뮬레이터로 재현 불가한 기능이 있으면 붙인다. |

## 개인정보 처리방침 URL

`앱 정보 → 일반 정보`에 있고 **버전 페이지에는 없다**. 비어 있으면 심사 제출
자체가 막히므로 Step 1에서 함께 확인한다.

## 스크린샷

App Store Connect의 업로드 영역에 표시된 픽셀 규격이 **유일한 권위**다. 이
문서의 값은 대조용이며, Step 5에서 `get_page_text`로 실제 문구를 읽어 확인한다.

| 기기 | 흔히 요구되는 규격 |
|---|---|
| iPhone 6.9" | 1290 × 2796 또는 1320 × 2868 |
| iPhone 6.5" | 1242 × 2688 또는 1284 × 2778 |
| iPad 13" | 2048 × 2732 또는 2064 × 2752 |

- 한 사이즈에 최대 스크린샷 10장, 앱 미리보기 3개.
- 스크린샷은 모든 디스플레이 크기·현지화에 재사용된다 — 한 세트만 잘 만들면
  된다.
- **앱 설치 시트에는 앞 3장만 노출된다.** 핵심 가치를 1~3번에 배치한다.
- `TARGETED_DEVICE_FAMILY`에 `2`가 있으면 iPad 스크린샷도 필수다. 없으면
  업로드가 아니라 제출 단계에서 막힌다.

## 심사에서 자주 걸리는 메타데이터 문제

| 유형 | 실패 예 | 대응 |
|---|---|---|
| 2.3.1 정확하지 않은 메타데이터 | 설명에 아직 없는 기능을 적음 | 기능 목록을 코드 근거와 1:1로 맞춘다. |
| 2.3.7 부적절한 키워드 | 경쟁 앱 이름·상표를 키워드에 넣음 | 일반 명사만 쓴다. |
| 2.1 정보 부족 | 심사 메모가 비어 있어 기능 재현 실패 | 2분 안에 핵심 기능에 도달하는 절차를 적는다. |
| 5.1.1 권한 설명 부실 | `NSMicrophoneUsageDescription`이 "마이크가 필요합니다" | 무엇에 쓰는지 목적을 적는다. 스캔에서 이런 문구를 발견하면 초안 6절에 수정 항목으로 올린다. |
| 3.1.1 결제 우회 | 설명에 외부 결제·웹 구독 언급 | 스토어 텍스트에서 외부 결제 언급을 뺀다. |

## 수출 규정

`ITSAppUsesNonExemptEncryption`이 Info.plist에 있으면 업로드마다 답하지 않아도
된다. 스캔에서 이 키가 없으면 초안 6절에 "빌드마다 수출 규정 질문에 답해야 함"
항목으로 남긴다.
