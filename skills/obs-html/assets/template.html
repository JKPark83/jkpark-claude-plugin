핵심 요약
  • 캐시는 브라우저와 CDN 두 곳에 있고, 가까운 쪽이 먼저 답한다.
  • 유효 기간이 지나도 파일이 그대로면 서버는 본문 없이 304만 돌려준다.
  • 파일 이름에 해시를 붙이면 기간을 1년으로 잡아도 안전하다.

왜 캐시인가

예시 본문이다. 문단은 3~5문장, 한 줄은 한글 40자 안팎이 읽기 편하다. 본문 폭(--measure)을 넓히지 않는다.

설정 예시

예시 본문. 같은 내용을 도구·언어별로 보여 줄 때는 탭을 쓴다.

Nginx

location /assets/ {
    add_header Cache-Control "public, max-age=31536000, immutable";
}

Express

app.use('/assets', express.static('dist/assets', {
  maxAge: '1y',
  immutable: true,
}));
팁

immutable은 "이 주소의 내용은 절대 안 바뀐다"는 약속이다. 파일 이름에 해시가 들어 있을 때만 붙인다.

흔한 실수

이전

Cache-Control: no-cache

"캐시하지 마라"로 읽기 쉽지만, 실제로는 매번 재검증하라는 뜻이다.

이후

Cache-Control: no-store

저장 자체를 막으려면 이쪽이다. 개인 정보가 담긴 응답에 쓴다.
