# 테마 (obs-html 3·6단계)

> 팔레트 21종 중 11종(`tufte`~`sottsass`)은 [conardli/garden-skills beautiful-article](https://github.com/conardli/garden-skills)
> (MIT)과 그 런타임 [reacticle](https://www.npmjs.com/package/reacticle) (MIT)에서, 10종(`ocean-depths`~`tech-innovation`)은
> [anthropics/skills theme-factory](https://github.com/anthropics/skills/tree/main/skills/theme-factory)
> (Apache-2.0)에서 가져왔다. 원본은 웹 폰트나 4색 팔레트를 쓰지만, 여기서는 **팔레트와 성격만**
> 오프라인 단일 HTML용 12색 토큰(라이트·다크)으로 옮겼다. 고르고 → 확인받고 → 일관되게
> 입히는 흐름은 theme-factory를 따른다.

테마는 **토큰 묶음**이다. 레이아웃·컴포넌트·다이어그램 규칙은 그대로 두고 값만 바꾼다.

- 색 12개: `--bg --paper --surface --ink --soft --muted --rule --accent --accent-tint --ext --warn --good`
- 모양 3개: `--head`(제목 글꼴), `--head-weight`(제목 굵기), `--radius`(상자 모서리)

본문 글꼴은 모든 테마에서 시스템 sans(`--sans`)로 둔다. 한글 명조는 긴 본문에서 기기마다
굵기와 자간이 달라 읽기 어렵기 때문이다. 테마 성격은 **제목 글꼴·색·모서리**로 낸다.

## 흐름

1. **후보 제시 (3단계 개요 확인과 같은 `AskUserQuestion`)** — 질문 header는 `테마`.
   - 1단계에서 고른 문서 유형의 추천 팔레트(`doc-types.md` 표)에서 주제에 맞는 3개를 고른다.
     첫 번째에 `(권장)`. 옵션은 4개까지라 나머지 팔레트는 질문에 다 못 넣는다.
   - 그래서 **질문 바로 앞 응답 본문에 21종 전체를 짧은 표(id · 이름 · 분위기 한 줄)로 보여 준다.**
     사용자가 "Other"에 표의 id를 적으면 그 팔레트로, "기본"이라 적으면 템플릿 기본값(흰 바탕 + 파랑)으로 간다.
   - 마지막 옵션은 **맞춤 테마**(주제에서 색을 뽑는다)로 둔다.
   - 옵션 설명에 분위기 한 줄과 바탕·글자·주색 hex를 적는다. `preview`에 아래 형식을 넣는다.

     ```
     Press · 출판 편집
     바탕 #fbf7ee  글자 #211e18  주색 #7b1e22
     제목: 명조 계열 700 · 모서리 0
     다크: 바탕 #1c1814  주색 #e08a85
     ```

2. **확인** — 사용자가 고른 테마로만 진행한다. 묻지 않고 임의로 고르지 않는다.
3. **적용 (6단계)** — `assets/themes.css`에서 고른 테마의 블록(`/* @theme {id} */`부터
   다음 `@theme` 앞까지, 다크 `@media` 포함)을 복사해 템플릿 `<style>`의 토큰 블록 바로
   뒤(`/* ── 기본` 앞)에 붙이고, `<html lang="ko" data-theme="{id}">`로 켠다.
   `:root[data-theme]`가 템플릿 `:root`보다 우선하므로 기본 토큰은 지우지 않아도 된다.
   **다른 테마 블록은 붙이지 않는다.**
4. 다이어그램(`.dg`)은 같은 토큰을 쓰므로 따로 칠하지 않는다. SVG 안에 hex를 직접 쓰지 않는다.

## 맞춤 테마

프리셋이 주제와 맞지 않거나 사용자가 맞춤을 고르면 주제 자체에서 모티프와 색을 찾는다.
예: 통화 정책 문서 → 음성 파형, 잉크 블루. 후보로 낼 때는 아래 형식을 쓴다.

```
이름: 통화 정책 문서
모티프: 음성 파형 — 차분한 잉크 블루, 변경 전후를 가르는 보조색
바탕 #F7F8FA (종이) · 글자 #1B2430 (잉크) · 주색 #2F5DA8 (전화 블루)
의미 색: 추가 #1F8A70 · 변경 #B7791F · 삭제 #B4443C
```

이름은 색 조합이 무엇을 닮았는지로 짓는다. 모티프는 대담함을 쓸 단 한 곳
(`html-template.md` "디자인 계획" 1번)과 이어져야 한다. 적용할 때는 `themes.css`의
블록과 같은 꼴로 `:root[data-theme="custom"]` 블록(색 12개 + 모양 3개, 다크 `@media`
포함)을 직접 써서 붙인다.

### 토큰 매핑

| 테마 역할 | 템플릿 토큰 | 규칙 |
|---|---|---|
| 밝은 바탕 | `--bg`, `--surface` | 긴 글을 읽는 문서라 라이트 모드 바탕은 밝게 둔다. 테마의 주색이 어두운 색이면 그 색은 다크 모드 `--bg`로 보낸다 |
| 바탕보다 한 단 진한 면 | `--paper`, `--rule` | 콜아웃·표 머리·코드 배경. 바탕과 명도 차이만 살짝 |
| 글자 | `--ink`, `--soft`, `--muted` | `--ink`는 바탕 대비 7:1 이상, `--muted`도 4.5:1 이상 |
| 주색 하나 | `--accent`, `--accent-tint` | 링크·핵심 그림의 강조 1~2곳. 주색을 둘 이상 두지 않는다 |
| 의미 색 | `--good`, `--warn`, `--ext` | 추가·변경·삭제처럼 문서가 실제로 구분해야 하는 것만. 색만으로 뜻을 전하지 않고 글자 라벨을 함께 둔다 |
| 제목 성격 | `--head`, `--head-weight`, `--radius` | 시스템 글꼴만 쓴다. 명조 계열은 `"AppleMyungjo", "Nanum Myeongjo", "Noto Serif KR"`을 한글 대체로 붙인다 |

- **글자로 쓰는 색은 `--bg`와 `--paper` 둘 다에 대해 4.5:1 이상.** 원색이 이보다 밝으면 같은
  색상(hue)에서 명도만 낮춘 값을 쓴다.
- **다크 값은 직접 만든다.** 같은 색상에서 바탕은 어둡게, 강조·의미 색은 밝게 올린다.
  라이트 값을 그대로 쓰거나 단순 반전하지 않는다.
- 대비는 계산해서 확인한다. 눈대중으로 넘기지 않는다.

```bash
python3 - <<'EOF'
def L(h):
    c = [int(h[i:i+2], 16) / 255 for i in (1, 3, 5)]
    c = [x / 12.92 if x <= .03928 else ((x + .055) / 1.055) ** 2.4 for x in c]
    return .2126 * c[0] + .7152 * c[1] + .0722 * c[2]
def ratio(a, b):
    hi, lo = sorted((L(a), L(b)), reverse=True)
    return (hi + .05) / (lo + .05)
for fg, bg in [("#2F5DA8", "#F7F8FA")]:   # 확인할 글자색/바탕색 쌍
    print(fg, bg, round(ratio(fg, bg), 2))
EOF
```
